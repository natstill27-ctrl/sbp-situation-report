# ระบบรายงานสถานการณ์ 3 จังหวัดชายแดนภาคใต้ (Standalone Web App)

เว็บแอปพลิเคชันแบบแยกตัว (Standalone Frontend Web App) สำหรับบันทึกเหตุการณ์ จับพิกัดอัตโนมัติ วิเคราะห์สถิติประกอบการจัดทำ **IPB (Intelligence Preparation of the Battlefield)** และเชื่อมต่อส่งข้อมูลเข้า **Google Apps Script / Google Sheets** ระบบเดิม ออกแบบตามแนวทาง **มาตรฐานเว็บไซต์ภาครัฐ**

## ความสามารถหลัก

1. **บันทึกเหตุการณ์แบบกระชับและจับพิกัดอัตโนมัติ**
   - รองรับ `Lat/Lng`, ลิงก์ `Google Maps`, `DMS` (องศา-ลิปดา-ฟิลิปดา), พิกัดทางทหาร `MGRS` และ `UTM (Zone 47N)` รวมถึงดึงพิกัดจากข้อความที่วาง
   - ปักหมุดลงแผนที่ทันที พร้อมคลิกหรือลากหมุดเพื่อปรับตำแหน่งจริง
   - ระบุ **จังหวัด / อำเภอ / ตำบล** อัตโนมัติแบบ Offline ครอบคลุม **3 จังหวัด (ปัตตานี, ยะลา, นราธิวาส) + 4 อำเภอ จ.สงขลา (จะนะ, เทพา, นาทวี, สะบ้าย้อย)** ทั้งหมด 37 อำเภอ 290 ตำบล (แจ้งเตือนหากอยู่นอกเขตแต่ยังบันทึกได้)
   - รองรับการสกัดวันที่ พื้นที่ และประเภทเหตุการณ์อัตโนมัติจากข้อความรายงานสไตล์ Paper (เช่น `เมื่อ ๙ พ.ย.๖๙ ... ต.แม่หวาด อ.ธารโต จว.ยะลา`)

2. **แดชบอร์ดเหตุการณ์และสถิติ (สำหรับวิเคราะห์ IPB / ทำ Paper / สไลด์)**
   - ตัวกรองช่วงวันที่ จังหวัด และประเภทเหตุการณ์
   - KPI Cards, กราฟแนวโน้มรายเดือน, กราฟเทียบรายจังหวัด/อำเภอสูงสุด, กราฟแยกตามประเภทเหตุการณ์ (แสดงตัวเลขบนกราฟโดยตรง)
   - ตารางเมทริกซ์พื้นที่ × ประเภทเหตุการณ์ พร้อม Export CSV และปุ่มคัดลอกสรุปสถิติเลขไทย / พิมพ์เป็น PDF

3. **แผนที่รวม รายการ และการส่งออกข้อมูล**
   - จัดเก็บสำรองในเครื่องด้วย IndexedDB ส่งซ้ำ (Retry) รายการที่ค้างได้
   - Export CSV (UTF-8 BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน)
   - คัดลอกข้อความรายงานส่ง LINE และรูปแบบ Paper (เลขไทย `๐-๙`)

4. **เชื่อมต่อ Google Apps Script เดิม (Dual-Write + ดึงข้อมูลย้อนหลัง)**
   - หน้า **ตั้งค่า & เชื่อมระบบเดิม** สำหรับกำหนด Webhook URL, ทดสอบการเชื่อมต่อ, จับคู่ชื่อคอลัมน์/ฟิลด์ และคัดลอกโค้ด **`SbpBridge.gs`**
   - รองรับการบันทึกคู่ขนาน (**Dual-Write**) ลงทั้งแท็บข้อมูลเต็ม (`สถานการณ์_3_จชต_IPB`) และชีตระบบเดิม (`ชีต1` 10 คอลัมน์ โดยใส่ประเภทเหตุ `"สถานการณ์ 3 จชต."`) เพื่อไม่ให้กราฟ/KML เดิมสะดุด รวมถึงรองรับการดึงข้อมูลย้อนหลังผ่าน `?page=json` พร้อมจัดกลุ่มไม่ให้นับซ้ำบนแดชบอร์ด IPB (ไม่เก็บ Token/ID จริงไว้ในซอร์สโค้ด)

## คำสั่งสำหรับพัฒนาและ Build

```bash
# ติดตั้งแพ็กเกจ
npm install

# รันทดสอบ Unit Tests
npm test

# รันโหมดพัฒนา (Dev Server)
npm run dev

# Build ไฟล์ Static สำหรับนำขึ้นเว็บเซิร์ฟเวอร์ (ผลลัพธ์อยู่ในโฟลเดอร์ dist/)
npm run build
```
